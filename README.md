# Skills

我自己写的 Claude skill，主要用来改变 Claude 讲解和分析问题的方式。

## paper-thinking：论文思维

讲概念、公式、定理、算法时，不从定义讲起，而是像写论文一样把它重新发明一遍：

- **需求**：当时要解决什么问题，最朴素的办法哪里不够用
- **资源**：手头有哪些已知结论和工具可以用
- **发现**：一步步怎么找到方法，每一步都说明为什么会想到
- **推理**：证明它对所有情况都成立，最后才给出教科书上的名字

适合问「为什么要有 X」「X 是怎么想到的」「这个公式怎么来的」的时候用。目标是让人觉得「换我站在那个位置，也能一步步走到这里」。

## first-principles-thinking：第一性原理

回答概括性、可拆解的问题时，不靠类比和流行说法，而是把问题拆到底层事实，再重新推出结论：

- 界定问题，检查问题本身有没有问错
- 列出常见回答背后的隐含假设，挑出最可疑的几条
- 从技术、经济、需求、制度、时间多个维度写出追问链，一直追问到物理规律、数学或稳健的经济规律这类「地基」
- 解释理论最优和现实之间的差距，做极端测试和反方论证
- 给出带可靠程度的结论和具体行动建议

适合「X 还值不值得做」「为什么 Y 这么贵」「该不该选 Z」「某行业会怎样」这类问题。

## 目录结构


## 安装

下载 `dist/` 里的 `.skill` 文件，在 Claude 的设置里找到 Skills，上传即可。
